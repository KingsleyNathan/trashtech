TrashTech Dashboard Documentation

Overview

The TrashTech Dashboard is a real-time monitoring system for smart trash cans, providing insights into fill levels, toxicity status, and waste classification.

Features

  • Real-time monitoring of trash fill levels
  • Toxic alert status tracking
  • Waste classification distribution
  • Email notifications for critical events

Alert Thresholds

  • Non-Biodegradable Fill Level: 90%
  • Recyclable Fill Level: 90%
  • Toxic Alert: "ABOVE NORMAL" or "TOXIC" status

Email Notifications

The system sends email alerts for:

  • Fill levels reaching or exceeding 90%
  • Toxic status changes to "ABOVE NORMAL" or "TOXIC"

Setup Instructions

  1. Clone the repository
  2. Install dependencies: pip install -r requirements.txt
  3. Configure environment variables in .env file
  4. Run the application: python app.py

Environment Variables

MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your.email@gmail.com
MAIL_PASSWORD=your_app_password
MAIL_DEFAULT_SENDER=your.email@gmail.com
ALERT_RECIPIENTS=recipient1@email.com,recipient2@email.com

API Endpoints

  • /api/dashboard-data - Get real-time dashboard data
  • /api/send-toxic-alert - Send toxic alert notifications
  • /api/send-fill-alert - Send fill level notifications
